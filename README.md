# كشفي — بناء APK

1. أنشئ مستودعاً جديداً على GitHub وارفع محتوى هذا المجلد كما هو.
2. افتح تبويب Actions، وشغّل Build APK (يعمل تلقائياً عند كل push).
3. بعد دقائق، نزّل الملف kachfy-apk من قسم Artifacts في أسفل صفحة التشغيل.
4. فكّ الضغط، وانقل app-debug.apk إلى هاتفك، ثم ثبّته (فعّل «التثبيت من مصادر غير معروفة»).

ملاحظة: هذا APK للتجربة (debug). للنشر على Google Play تحتاج نسخة موقّعة (release/AAB).
